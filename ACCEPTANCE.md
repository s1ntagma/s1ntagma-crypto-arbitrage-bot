# Приёмка latbot (по промпту FUNCTIONALITY FIRST)

Обновлено: 2026-10-08. Проверка: `python -m pytest -q` (520 тестов, офлайн, включая
браузерный тест Playwright на реальном сервере) + живой запуск на ПК владельца (вкладка DIAG).

| Критерий | Статус | Чем подтверждено |
|---|---|---|
| FUNCTIONALITY | ✅ PASS | Сквозные тесты: стаканы → сигнал → возможность → MANUAL/AUTO → сделка → P&L → статистика |
| DATA | ✅ PASS | Живой запуск: 13 из 14 бирж, 610 монет, ~276 000 тиков за сессию |
| SIGNAL ENGINE | ✅ PASS | Живой запуск: 1 238 движений, 26 сигналов, 1 настоящая возможность; каждый отказ посчитан по причине |

| DESIGN | ⏸ НЕ НАЧАТ | По приоритету промпта: дизайн после полной проверки функционала |

## Не проверено и почему
- **LIVE-торговля реальными ордерами**: нет API-ключей бирж. Работает только PAPER.
- **Telegram вживую**: бот не может писать владельцу, пока тот не нажмёт /start.
- **Анализ скриншотов вживую**: код проверен с тестовым клиентом Claude; живой вызов — после первой сделки с ключом в `.env`.

## Где смотреть «почему нет сигналов»
Вкладка **DIAG** или `/diag` в Telegram: воронка от тиков до алертов и причины отказа
(одна биржа, объём мал / неизвестен, нет свежих данных, направление, лаг, стакан, комиссии, edge, ликвидность).
