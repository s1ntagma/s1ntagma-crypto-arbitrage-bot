# Результаты стратегии

Только чтение базы. Ордеров не отправляет, настройки сам не меняет, `.env` не читает.

## Откуда данные

- `GET /api/trades` - сделки: `expected_net_pct`, `actual_net_pct`, `realized_pnl_quote`, `diff_reason`, `execution_time_s`.
- `GET /api/stats` - по (монета, биржа): медиана задержки реакции, catch-up ratio, частота first mover,
  средняя длительность окна, success rate, false signals, средний slippage, задержка API.
- `GET /api/opportunities?state=history` - истёкшие и исполненные возможности с причиной.
- `python -m latbot.backtest data/market/*.jsonl` - прогон по записанным данным.

## Как читать

- Меньше 20-30 закрытых сделок - статистика шумная, выводы делать рано. Скажи это прямо.
- Главная метрика - разрыв expected vs actual NET и его причина (slippage, latency, недодогон).
  Большой разрыв = завышенный catch-up ratio или заниженная оценка задержки, а не «рынок плохой».
- Смотри группы отдельно: биржа A может реагировать за 2 с, биржа B - за 15 с.
- PAPER-результат включает модель комиссий и проскальзывания, но не обещает того же на LIVE.

## Чего не делать

- Не подгонять параметры под прошлые сделки. Статистика учится сама (`StatsStore`); ручные правки - по одной,
  по решению владельца, с записью «что и зачем».
- Не называть `probability` в светофоре вероятностью прибыли - это грубая оценка исполнимости.
